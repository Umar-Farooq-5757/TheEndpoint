# The Endpoint

An API testing tool inspired by POSTMAN.

## Core features include:
- Different methods for making API calls (GET, POST, PUT, DELETE).
- Send custom headers with request body like "Content-Type":"application/json".
- Light/Dark mode supported.
- API response is shown in beautifully highlighted JSON format.

## Tech Stack:
- Vite with React
- TailwindCSS for styling
- Axios for making API calls
- react-json-view for formatting/highlighting JSON
- Lucide react for icons
- react-hot-toast for showing popup notifications

## How to use?
1. Write the URL on which you want to make request.
2. Select the method (GET, POST, PUT, DELETE)
3. Add request body as JSON for POST and PUT requests.
4. Add headers (optional)
5. Send the request.
